\sectioncentered*{Перечень условных обозначений}

БЗ~--~база знаний;

ГИС~--~гибридная интеллектуальная система;

ПрО~--~предметная область;

API (Application Programming Interface)~--~программный интерфейс приложения;

JSON (JavaScript Object Notation)~--~текстовый формат обмена данными;

LLM (Large Language Model)~--~большая языковая модель;

OWL (Web Ontology Language)~--~язык описания онтологий;

RAG (Retrieval-Augmented Generation)~--~дополнение генерации извлечением;

RDF (Resource Description Framework)~--~модель представления данных в виде троек
«субъект~--~предикат~--~объект».
