# Игровой ассистент для Minecraft

Гибридная интеллектуальная система: курсовая работа 7-го семестра, БГУИР, кафедра ИИТ.

Игрок пишет или говорит в игре на естественном языке, ассистент понимает запрос и помогает:
выдаёт предметы, строит план достижения цели от текущего инвентаря, объясняет выбор, ведёт
по кампании к дальней цели, отвечает на вопросы о мире игры и отказывает в недопустимом с
объяснением причины. В выживании по просьбе «сделай сам каменную кирку» ассистент может
выполнить план решателя сам — после показа плана и «да» игрока.

Языковая модель отвечает за понимание речи и формулировку ответа. Факты, планы и проверки
дают онтология игрового мира и решатель — поэтому недопустимое действие нельзя получить
никакой формулировкой запроса.

## Как устроено

```
мод Minecraft (Fabric 1.20.1) или страница /chat
        │  реплика, инвентарь
        ▼
сервер FastAPI ── orchestrator: модель → резолвер → решатель → модель
                     ├─ resolver  — слова игрока → объект онтологии
                     ├─ solver    — план, проверки, задания, кампания, древо развития
                     └─ kb        — онтология RDF/OWL из данных игры
```

Подробное описание архитектуры, модулей и подводных камней — в [CLAUDE.md](CLAUDE.md).

## Быстрый старт

Нужны Python 3.13, JDK 17 и Git.

```bash
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements-dev.txt
```

Ключи провайдеров языковых моделей — в файле `.env` в корне (в репозиторий не входит):

```
GROQ_API_KEY=...
DEEPSEEK_API=...
OPENROUTER_API_KEY=...
TAVILY_API_KEY=...
```

База знаний собирается из файлов игры, поэтому сначала собирается мод — сборка скачивает
клиент Minecraft:

```bash
cd mod/minecraft-mod && ./gradlew.bat build && cd ../..
.venv/Scripts/python.exe -m kb.fetch_locale
.venv/Scripts/python.exe -m kb.extract
.venv/Scripts/python.exe -m kb.build
```

Запуск сервера — `scripts/start_server.bat` или:

```bash
.venv/Scripts/python.exe -m uvicorn main:app --port 8000
```

| Страница | Что на ней |
|---|---|
| `/chat` | разговор с ассистентом без игры, голосовой ввод и озвучивание |
| `/compare` | одна реплика в двух конфигурациях: только модель и гибрид |
| `/tree` | древо развития и положение игрока на нём |
| `/dashboard`, `/admin` | панель управления, журналы, настройки модели |

Клиент игры с модом — `scripts/start_minecraft_client.bat`. В игре клавиша `O` открывает
оверлей: статус, рецепты, план, кампания, древо.

«Сделай сам» по умолчанию выключен: `"enabled": true` в разделе `autopilot` файла
`settings.json`. Работает только в одиночной игре в режиме выживания. Ассистент показывает
план и спрашивает «Начать?»; остановка — клавиша `K`, любое движение или «стоп» в чате,
продолжение — «продолжай». Добывать блоки он умеет только с установленным
[Baritone](https://github.com/cabaletta/baritone) (`baritone-api-fabric-1.10.1.jar` в папке
`mods`, лицензия LGPL-3.0, ставится отдельно); без него просит принести нужное, а крафт,
печь и установку верстака делает сам. Охота, Незер и Край, руды под железную кирку — не
входят.

Тесты:

```bash
.venv/Scripts/python.exe -m pytest tests -q --ignore=tests/test_ui_smoke.py
```

## Структура

| Каталог | Содержимое |
|---|---|
| `api/` | HTTP-слой сервера: чат, кампания, сравнение, древо, голос, админка |
| `orchestrator/` | конвейер обработки реплики, извлечение намерения, формулирование ответа |
| `resolver/` | сопоставление свободной речи с объектами онтологии |
| `solver/` | планировщик, валидатор, задания, кампания, древо, разбор гибели |
| `search/` | поиск в сети: Tavily, DuckDuckGo, отбор по релевантности |
| `vision/` | распознавание экрана: снимок окна игры, разбор кадра моделью зрения |
| `kb/` | извлечение данных игры и сборка онтологии |
| `eval/` | оценочный контур: размеченный набор реплик, сравнение конфигураций, отчёты |
| `mod/minecraft-mod/` | клиентский мод Fabric |
| `static/`, `frontend/` | веб-страницы |
| `voice/` | отдельный сервис синтеза речи со своим окружением |
| `report/` | пояснительная записка (LaTeX) и собранный PDF |
| `docs/` | замысел, план защиты, передача контекста, проектные заметки |
| `scripts/` | запуск сервера и клиента игры |
| `tests/` | компонентные, интеграционные и сквозные тесты |
| `legacy/` | архивная подсистема, в работе ассистента не участвует |
